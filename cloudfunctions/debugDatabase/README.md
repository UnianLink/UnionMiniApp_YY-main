# 数据库调试工具

## 功能概述
提供数据库数据的查询和调试功能，帮助开发者和运营人员检查碰一碰数据、用户信息和系统状态。

## 核心功能
- **用户数据检查**：查询指定用户的详细信息和配置
- **用户列表查看**：获取系统中所有用户的概览信息
- **朋友关系调试**：检查用户的碰一碰记录和社交关系
- **集合状态监控**：列出数据库中的所有数据集合
- **系统总览**：提供数据库整体状态的快速概览

## 调试操作

### checkUser（检查用户）
查询指定用户的完整信息：
- 个人资料和标签配置
- 设备信息和编码数据
- 账户创建和更新时间

### listUsers（用户列表）
获取所有用户的基础信息：
- 用户数量统计
- 基本身份信息
- 注册时间分布

### checkFriends（朋友关系）
检查用户的社交数据：
- 碰一碰记录列表
- 好友设备信息
- 相遇频次统计
- 关系建立时间

### collections（集合列表）
列出数据库中的数据集合：
- 集合名称和结构
- 数据量统计
- 权限配置状态

### 默认总览
不指定操作时的系统概览：
- 用户总数
- 活跃用户统计
- 数据健康状态

## 技术实现
- **多操作路由**：根据action参数分发到不同的查询函数
- **安全查询**：只读操作，不会修改任何数据
- **结构化输出**：返回格式化的JSON数据便于分析
- **错误处理**：优雅处理各种查询异常情况

## 使用场景
- **开发调试**：在功能开发过程中验证数据正确性
- **问题排查**：当用户反馈问题时快速定位数据异常
- **运营分析**：了解用户行为和系统使用情况
- **数据迁移**：在数据结构变更时验证迁移结果

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- 所有数据集合的读权限
- 管理员级别的调用权限

## 安全考虑
- 建议仅在开发和测试环境中使用
- 生产环境需要添加管理员身份验证
- 敏感数据需要进行脱敏处理
- 定期清理调试日志

## 产品价值
作为运维和调试的重要工具：
- 提高问题排查效率
- 保障数据质量和一致性
- 支持产品功能的持续优化
- 为决策提供数据支撑
