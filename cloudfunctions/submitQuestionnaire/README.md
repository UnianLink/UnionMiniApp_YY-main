# 问卷数据提交器

## 功能概述
处理用户提交的问卷数据和兴趣标签配置，支持新旧数据格式，是用户信息收集和存储的核心接口。

## 核心功能
- **双格式支持**：同时支持传统问卷和新式标签配置数据
- **智能路由**：根据数据类型自动选择相应的处理流程
- **编码验证**：验证兴趣标签的二进制编码格式和长度
- **版本管理**：支持v1.0和v2.0数据格式的混合处理
- **完整性检查**：确保提交数据的完整性和有效性

## 数据处理类型

### 高级标签数据（主要）
存储到`users_adv`集合：
- **兴趣标签**：职业、兴趣、性格、奇特标签四大类
- **编码信息**：6位二进制平面编码，支持硬件快速匹配
- **蓝牙名称**：以"Un"开头的设备标识符
- **新格式字段**：阈值、唯一ID、状态码等扩展信息
- **版本标识**：v1.0（传统）或v2.0（新格式）

### 传统问卷数据（兼容）
存储到`users_bar`集合：
- 用户基础信息
- 问卷选择题答案
- 历史兼容数据

## 新格式特性（v2.0）

### 扩展字段
- **阈值设置**：匹配灵敏度控制（0-63范围）
- **唯一ID**：设备识别码（0-4095范围）
- **状态码**：设备工作状态标识
- **配置哈希**：标签配置的唯一标识

### 编码系统
- **字符集**：64字符集（A-Z, a-z, 0-9, _, -）
- **编码长度**：标准14字符（可扩展至25字符）
- **名称格式**：`Un + 编码字符串`（如"UnABCDE..."）

## 数据验证规则

### 基础验证
- 显示名称非空
- 至少选择4个兴趣标签
- 编码长度在合理范围内（10-25字符）

### 新格式验证
- 阈值在0-63范围内
- 唯一ID在0-4095范围内
- 状态码为'0'或'1'

## 技术实现
- **条件分发**：根据`advancedTags`字段判断数据类型
- **原子操作**：使用upsert模式确保数据一致性
- **元数据记录**：保存编码算法、版本等技术信息
- **兼容性处理**：向下兼容旧版本数据格式

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- `users_adv`和`users_bar`集合写权限
- 用户身份认证服务
- 默认配置管理（硬件同步）

## 产品价值
这个云函数是Unian产品的数据入口，负责：
- 收集用户兴趣和性格信息
- 生成设备识别码和匹配参数
- 为"碰一碰"功能提供基础数据
- 支持产品功能的持续升级和扩展

## 提交流程
1. **数据接收**：接收小程序提交的用户数据
2. **格式识别**：判断是高级标签还是传统问卷
3. **数据验证**：检查必填字段和格式规范
4. **编码处理**：验证和存储兴趣标签编码
5. **数据库操作**：更新或创建用户记录
6. **结果返回**：返回处理状态和关键信息
