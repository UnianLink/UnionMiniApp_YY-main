# 测试数据生成器

## 功能概述
自动生成大量的模拟用户数据，用于系统测试、功能验证和演示展示，支持自定义配置和批量生成。

## 核心功能
- **批量用户生成**：一次性创建大量测试用户账号
- **随机信息填充**：自动生成昵称、城市、年龄等基础信息
- **问卷数据模拟**：随机选择问卷答案，模拟真实用户行为
- **配置化生成**：通过配置文件自定义生成规则和数据范围

## 生成内容

### 基础信息
- **随机昵称**：结合前缀、姓名、后缀的组合生成
- **地理位置**：覆盖主要省份和城市的随机分布
- **人口统计**：年龄、性别、职业等基础属性
- **头像信息**：随机分配默认头像资源

### 问卷数据
- **兴趣偏好**：随机选择各类兴趣标签组合
- **行为特征**：模拟用户的使用习惯和偏好选择
- **社交属性**：生成符合统计规律的社交倾向数据
- **技术态度**：对新技术和设备的接受度模拟

## 配置系统
- **数据范围控制**：设置生成数据的取值范围和分布
- **真实性保证**：确保生成数据符合业务逻辑
- **多样性平衡**：避免数据过于单一或极端
- **可扩展配置**：支持新增字段和生成规则

## 技术实现
- **随机算法**：使用多种随机策略保证数据多样性
- **配置驱动**：通过外部配置文件控制生成逻辑
- **批量处理**：优化数据库写入性能
- **数据验证**：确保生成数据的完整性和有效性

## 使用场景
- **功能测试**：为新功能提供充足的测试数据
- **性能测试**：验证系统在大数据量下的表现
- **演示准备**：为产品演示创建丰富的示例数据
- **算法验证**：为推荐算法提供多样化的训练数据

## 依赖配置
- **questionnaire-config.js**：问卷配置和选项定义
- **config-guide.md**：配置文件使用说明
- **questionnaire-config-example.js**：配置示例文件

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- `users_bar`集合写权限
- 配置文件读取权限

## 数据质量保证
- **逻辑一致性**：确保生成数据符合业务规则
- **统计合理性**：生成数据的分布符合真实场景
- **去重机制**：避免生成重复的用户标识
- **清理功能**：提供测试数据的清理和重置功能

## 安全提醒
- 仅在开发和测试环境中使用
- 生产环境应禁用此功能
- 定期清理测试数据避免污染正式数据
- 注意保护配置文件中的敏感信息
