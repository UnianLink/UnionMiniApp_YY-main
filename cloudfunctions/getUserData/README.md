# 用户数据获取器

## 功能概述
获取用户的个人资料和问卷数据，支持多种数据格式和场景，是小程序与云端数据交互的核心接口。

## 核心功能
- **多格式支持**：支持获取高级标签数据、原始问卷数据或两者组合
- **朋友数据扩展**：可选择包含用户的社交关系和碰一碰记录
- **MBTI数据更新**：支持实时更新用户的性格类型和相关配色
- **头像URL处理**：自动处理云存储头像文件的临时访问链接
- **灵活身份识别**：支持当前用户和指定用户数据获取

## 数据类型

### 高级标签数据（默认）
从`users_adv`集合获取：
- 用户的兴趣标签配置
- 唯一ID分配信息
- 蓝牙设备名称
- MBTI性格类型
- 设备配色方案

### 原始问卷数据（兼容）
从`users_bar`集合获取：
- 传统问卷答案
- 基础个人信息
- 历史数据记录

### 朋友关系数据（可选）
包含用户的社交信息：
- 碰一碰记录
- 好友设备信息
- 相遇次数统计
- 注册状态标识

## 特殊功能

### MBTI数据更新
支持实时更新用户的性格类型：
- 更新MBTI测试结果
- 同步相应的设备配色
- 保持数据版本一致性

### 头像处理
自动处理云存储头像：
- 获取临时访问链接
- 处理过期URL更新
- 降级到默认头像

## 技术实现
- **条件查询**：根据openid精确匹配用户记录
- **时间排序**：获取用户最新的数据记录
- **异常处理**：优雅处理各种查询失败场景
- **数据脱敏**：在日志中对敏感信息进行脱敏处理

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- `users_adv`和`users_bar`集合读权限
- 云存储文件访问权限
- 用户身份认证服务

## 产品价值
作为数据获取的统一入口，这个云函数支撑了小程序的核心功能：
- 用户个人资料展示
- 设备配置信息同步
- 社交关系管理
- 兴趣匹配计算
- 个性化体验定制

## 调用示例

```javascript
// 获取当前用户高级标签数据
{ dataType: 'advanced' }

// 获取指定用户数据（包含朋友信息）
{ openid: 'user123', includeFriends: true }

// 更新用户MBTI信息
{ 
  action: 'updateMBTI',
  mbtiData: {
    'advancedTags.mbtiType': 'ENFP',
    'advancedTags.idleLightColor': '#FF6B6B'
  }
}
```
