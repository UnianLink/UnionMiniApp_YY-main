# 用户分类器

## 功能概述
根据用户问卷答案将所有用户智能分类到不同的兴趣社群中，为社交匹配和主题活动提供数据支持。

## 核心功能
- **智能分类**：基于问卷答案将用户归类到4大主题的16个细分社群
- **批量处理**：一次性处理所有用户数据，支持大规模用户分类
- **动态更新**：每次运行都会刷新分类结果，反映最新的用户状态
- **结构化存储**：将分类结果存储为便于查询和展示的数据结构

## 分类体系

### 🏛️ 数码轨迹博物馆
基于用户的第一台数码设备经历：
- **🧑‍🚀 原始信号守望者**：BB机/寻呼机时代用户
- **🕹️ 掌上文明缔造者**：功能手机时代用户  
- **🌐 云端原居民**：MP3/PSP/iPod时代用户
- **🧭 设备极简主义者**：智能设备及以后用户

### 🎭 感官沉浸研究所
基于用户最重要的设备偏好：
- **🎨 视觉主义者**：以手机为主的用户
- **🎧 声波感应者**：以平板/笔记本为主的用户
- **🤲 触觉掌控者**：以智能手表/手环为主的用户
- **🧠 思维沉浸者**：以智能音箱为主的用户

### 🚀 行为方式匹配站
基于用户对AI新技术的态度：
- **🚀 快速尝鲜玩家**：马上尝试新技术
- **👓 信息观察者**：理性观望新技术
- **📷 内容创作者**：让朋友先试新技术
- **🛸 安静探索者**：拒绝使用新技术

### 🌟 能量节律星球
基于用户学习新事物的偏好：
- **🌞 晨光规划者**：喜欢看视频学习
- **☀️ 午间聚能人**：喜欢读说明学习
- **🌌 夜间灵感族**：喜欢直接上手学习
- **🌫️ 随境波动者**：喜欢听人推荐学习

## 技术实现
- **批量数据处理**：使用分页查询处理大量用户数据，避免内存溢出
- **映射算法**：将用户答案选项映射到对应的社群分类
- **数据结构优化**：将分类结果转换为数组格式，便于前端展示
- **原子性更新**：先清空旧数据再写入新结果，确保数据一致性

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- `users_bar`集合读权限（用户问卷数据）
- `class_bar`集合写权限（分类结果存储）

## 产品价值
这个分类系统是Unian社交功能的基础，通过将用户按兴趣和行为特征分群，可以：
- 在展会现场为用户推荐同类型的人群
- 为不同社群定制专属的互动体验
- 提供个性化的内容和活动推荐
- 帮助主办方了解参会者构成

## 使用场景
- 定期更新用户分类数据（建议每日或每周执行）
- 展会活动前的用户画像分析
- 新功能上线前的用户群体洞察
