# 碰一碰数据同步器

## 功能概述
接收硬件设备上传的碰一碰记录，查询相关用户信息，计算兴趣匹配度，并返回匹配结果供小程序展示。

## 核心功能
- **设备数据接收**：接收硬件上传的附近设备蓝牙名称列表
- **用户信息查询**：根据蓝牙名称查找对应的注册用户信息
- **匹配度计算**：基于兴趣标签计算用户间的兴趣相似度
- **社交关系更新**：更新用户的朋友列表和相遇记录
- **实时数据同步**：提供最新的碰一碰状态给前端展示

## 业务流程
1. **数据接收**：获取硬件上传的设备列表（包含信号强度、时间戳等）
2. **身份识别**：根据蓝牙名称（如"UnABCD..."）查询对应用户
3. **匹配分析**：
   - 解析用户的兴趣标签编码
   - 计算与当前用户的兴趣重叠度
   - 生成匹配评分和推荐理由
4. **关系更新**：
   - 更新双方的朋友列表
   - 记录相遇时间和地点
   - 累计相遇次数统计
5. **结果返回**：返回处理后的匹配结果和用户信息

## 匹配算法
- **标签重叠度**：计算共同兴趣标签的数量和权重
- **相似度评分**：基于多维度特征计算综合匹配分数
- **推荐优先级**：根据匹配度和相遇频次排序推荐结果
- **阈值过滤**：只返回达到最低匹配度的用户

## 数据处理
- **注册状态识别**：区分已注册用户和未注册设备
- **信息脱敏**：保护用户隐私，只展示必要信息
- **时效性处理**：优先处理最新的碰一碰记录
- **异常容错**：处理设备名称解析失败等异常情况

## 技术实现
- **批量查询优化**：使用高效的数据库查询策略
- **标签解码**：解析6位二进制编码的兴趣标签
- **关系图更新**：维护用户间的社交关系网络
- **实时性保障**：快速响应硬件的同步请求

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- `users_adv`集合读写权限
- 用户身份认证服务
- 标签编码解析算法

## 产品价值
这是Unian"碰一碰"功能的核心引擎：
- **智能匹配**：为用户发现志趣相投的朋友
- **社交促进**：降低陌生人社交的心理障碍
- **数据驱动**：基于真实兴趣进行精准推荐
- **实时体验**：提供即时的社交反馈

## 使用场景
- 用户在展会现场使用设备时的实时同步
- 活动结束后的批量数据处理
- 社交关系的动态更新和维护
