# 唯一ID分配器

## 功能概述
为具有相同兴趣标签配置的用户分配唯一的数字ID，确保硬件设备能够准确识别和匹配用户。

## 核心功能
- **智能ID分配**：为每个用户的标签组合分配一个0-4095范围内的唯一ID
- **配置变更检测**：当用户修改兴趣标签时，自动释放旧位置并重新分配
- **位置重用机制**：释放的ID位置可供新用户使用，提高空间利用率
- **实时统计**：提供详细的ID使用情况和容量分析

## 业务逻辑
1. **哈希匹配**：根据用户选择的标签组合生成配置哈希值
2. **查找同类**：查找具有相同配置哈希的其他用户
3. **位置分析**：统计已使用的ID位置，找到最小可用编号
4. **智能分配**：
   - 配置未变更：保持原有ID
   - 配置变更：释放原位置，分配新ID
   - 新用户：从0开始寻找第一个可用位置

## 技术实现
- **数据存储**：基于微信云开发数据库的`users_adv`集合
- **编码系统**：将数字ID编码为2字符蓝牙名称格式（如：0→"AA", 1→"AB"）
- **容量管理**：支持最多4096个不同ID（64×64字符组合）
- **事务处理**：保证分配过程的原子性和一致性

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- 云数据库访问权限
- 用户身份认证服务

## 产品价值
这个云函数是Unian产品的核心组件，实现了"碰一碰"功能中设备间的精确匹配。通过为相同兴趣的用户分配连续的ID范围，硬件设备可以快速判断附近用户的兴趣匹配度，从而触发相应的灯光效果和社交提示。

## 使用场景
- 用户首次完成兴趣标签设置
- 用户修改个人兴趣标签配置
- 系统进行用户数据迁移或重组
