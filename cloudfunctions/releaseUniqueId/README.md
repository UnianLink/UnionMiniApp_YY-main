# 唯一ID释放器

## 功能概述
释放用户不再使用的唯一ID位置，让该位置可以被其他用户重新使用，确保ID资源的高效利用。

## 核心功能
- **位置释放**：删除用户的旧标签配置记录，释放其占用的ID位置
- **身份验证**：确保只有原用户才能释放自己的ID位置
- **数据清理**：彻底移除过期的配置记录，保持数据库整洁
- **释放确认**：提供详细的释放操作结果反馈

## 业务逻辑
1. **身份校验**：验证用户身份和释放请求的合法性
2. **记录查找**：根据旧配置哈希和ID精确定位待释放的记录
3. **数据删除**：从数据库中完全移除该用户的旧配置记录
4. **结果反馈**：返回释放操作的详细状态信息

## 技术实现
- **精确查询**：基于openid、tagConfigHash、uniqueId三重匹配确保准确性
- **安全删除**：使用数据库的remove操作彻底删除记录
- **事务保护**：确保删除操作的原子性，避免数据不一致

## 使用场景
- **配置变更时**：用户修改兴趣标签前先释放旧位置
- **系统清理时**：定期清理不再需要的过期配置
- **数据迁移时**：在数据重组过程中释放临时占用的位置

## 依赖服务
- 微信云开发SDK (`wx-server-sdk`)
- 云数据库写权限
- 用户身份认证服务

## 产品价值
作为ID分配系统的配套功能，确保4096个ID位置能够被充分循环利用。当用户修改兴趣标签时，旧的位置会被释放给其他相同配置的用户，避免ID资源浪费，保证系统的可持续运行。

## 工作流程
通常与`allocateUniqueId`云函数配合使用：
1. 用户修改标签 → 调用`releaseUniqueId`释放旧位置
2. 释放成功 → 调用`allocateUniqueId`分配新位置
3. 新位置分配成功 → 更新设备的蓝牙名称
