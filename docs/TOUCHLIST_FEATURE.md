# 碰一碰社交功能实现文档

## 功能概述
成功实现了碰一碰设备列表的社交功能，允许硬件设备将碰一碰的设备列表上传到小程序，并在朋友页面展示匹配的用户和未注册设备。

## 实现内容

### 1. 后端架构
- **数据库结构**
  - `users_adv` 集合新增 `bluetoothName` 字段存储完整的16字符蓝牙名称
  - `users_adv` 集合新增 `touchList` 字段存储碰一碰设备列表
  - 新建 `touch_records` 集合记录所有碰一碰事件

### 2. 云函数实现
#### submitQuestionnaire (已修改)
- 在保存用户标签时，同时生成并保存 `bluetoothName` 字段
- 格式：`Un` + 14字符编码

#### syncTouchList (新增)
- 接收硬件上传的碰一碰设备列表
- 根据蓝牙名称匹配已注册用户
- 计算标签匹配度
- 返回匹配用户和未匹配设备

### 3. 小程序端实现

#### device.js (设备连接页面)
- 新增 `syncTouchListToCloud()` 函数处理碰一碰列表同步
- 在接收到 `touch_list` 类型的JSON数据时自动调用云函数
- 将匹配结果存储到本地供朋友页面使用

#### connect.js (朋友页面)
- 页面标题从"连接"改为"朋友"
- 新增 `loadTouchListResult()` 函数加载碰一碰结果
- 优先显示碰一碰的朋友，其次显示未匹配设备
- 为匹配用户显示共同标签和匹配度

#### 界面优化
- 添加碰一碰标识徽章
- 显示匹配的共同标签（高亮显示）
- 显示匹配度分数
- 记录首次碰一碰时间

## 数据流程

```
硬件设备 → BLE发送touch_list → device.js接收 → 调用syncTouchList云函数 
→ 匹配用户数据 → 存储结果 → connect.js展示朋友列表
```

## 关键特性

1. **自动同步**: 收到碰一碰列表后自动同步到云端，无需用户手动确认
2. **智能匹配**: 根据蓝牙名称自动匹配已注册用户
3. **标签匹配度**: 计算并显示共同标签数量
4. **混合显示**: 已匹配用户和未注册设备在同一列表展示
5. **视觉区分**: 通过徽章和颜色区分碰一碰朋友和普通用户

## 使用流程

1. 用户填写标签问卷后，系统自动生成蓝牙名称
2. 硬件设备之间碰一碰，记录设备列表
3. 硬件连接小程序时上传碰一碰列表
4. 小程序自动匹配用户并显示在朋友页面
5. 用户可查看匹配的朋友和共同标签
